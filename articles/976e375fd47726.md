## はじめに

AWS Trainium は、AWS が自社で設計している機械学習向けのチップです。この記事では、初代 Trainium、Trainium2、Trainium3 の 3 世代について、性能の伸び、チップの中の構成、世代ごとに加わった機能を順に見ていきます。公式ドキュメントは推論向けの AWS Inferentia も含めて世代を数えるので、初代 Trainium を第 2 世代、Trainium3 を第 4 世代と呼んでいます。この記事は Inferentia を扱わず、Trainium の 3 世代だけを数えます。

## 3 世代で性能はどれだけ伸びたか

![チップ 1 枚あたりの性能は、初代 Trainium と比べて FP8 の計算が 13.2 倍、チップ間の通信が 6.7 倍に伸びた](/images/976e375fd47726-trainium-perf-3d.png)

FP8 は、8 ビットで 1 つの数を表す浮動小数点の形式です。棒の高さは、公式の仕様にあるチップ 1 枚あたりの値を、初代 Trainium を 1 倍として表した倍率です。手前から奥へ、Trainium、Trainium2、Trainium3 の順に並べています。FP8 の計算は、初代と Trainium2 の cFP8 から Trainium3 の MXFP8 まで、3 世代で 13.2 倍に伸びました。MXFP4 は Trainium3 で加わった形式です。公式の値は MXFP8 と同じ 2,517 TFLOPS なので、棒も Trainium3 の FP8 と同じ高さにしています。TFLOPS は 1 秒あたりの計算の回数を兆単位で表した値で、容量は置けるデータの量、帯域は 1 秒あたりに運べるデータの量です。

倍率は、[Trainium のページ](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-hardware/trainium.html)の値（FP8 と BF16 は 190 TFLOPS）を基準に計算しました。HBM 帯域とチップ間の通信は、[Trainium2 のページ](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-hardware/trainium2.html)の比較表にある初代の値（0.8 TB/s と 384 GB/s）を基準にしています。この記事の倍率は 190 を基準にしているので、Trainium2 の FP8 は 6.8 倍、BF16 は 3.5 倍です。Trainium2 のページの比較表は初代を 191 TFLOPS とし、同じ比較を 6.7 倍と 3.4 倍と書いています。

## チップの中の構成の移り変わり

![Trainium は 2 コアから 8 コアに増え、Trainium3 ではチップ同士のつなぎ方が格子状からスイッチを通す形に変わった](/images/976e375fd47726-trainium-arch-evolution.png)

1 枚のチップには、NeuronCore（NC）という計算の単位が並び、HBM（High Bandwidth Memory）という大容量の速いメモリがつながっています。NeuronLink はチップ同士をつなぐ専用の通信路で、CC-Cores はチップ同士の通信を取り仕切るコアです。緑の札は、その世代で加わった主な機能です。Trainium2 の点線の枠は、あとで説明する LNC=2 のまとまりです。図の下の段はチップ同士のつなぎ方で、Trainium3 では格子状のつなぎ方から、スイッチを通して全部のチップがやり取りできる形に変わりました。

## NeuronCore の 4 つのエンジン

この記事で扱う [NeuronCore-v2](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-hardware/neuron-core-v2.html)、[v3](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-hardware/neuron-core-v3.html)、[v4](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-hardware/neuron-core-v4.html) は、どれも役割の違う 4 つのエンジンと、プログラムが管理する SRAM（コアの中にある高速なメモリ）を持っています。

- Tensor Engine は、行列の掛け算や畳み込みのような大きな計算を受け持ちます
- Vector Engine は、出力の 1 つ 1 つを、たくさんの入力から求める計算を受け持ちます。Layer Normalization がその例です
- Scalar Engine は、出力の 1 つ 1 つを、入力 1 つから求める計算を受け持ちます
- GPSIMD Engine は、C で書いた計算をコアの上で動かせるプロセッサです

## 初代 Trainium で加わった機能

初代 Trainium は、1 枚に [NeuronCore-v2](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-hardware/neuron-core-v2.html) を 2 個載せています。

- GPSIMD Engine は、この世代で新しく加わりました。512 ビット幅のプロセッサ 8 個からなり、自作の計算（カスタムオペレータ）を動かせます
- 動的な形状と制御フローに対応しました。入力の大きさが変わるモデルや、分岐やループを含むモデルも動かせます
- 丸め方を選べるようになりました。標準の RNE（Round Nearest, ties to Even）は、いちばん近い値に丸め、ちょうど中間なら偶数の側に丸める方式です。[Stochastic Rounding](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-features/rounding-modes.html) は、近い 2 つの値までの距離に応じて、丸め先を確率で選びます。大きな数に小さな数を何度も足すとき、小さな増分が結果に積み重なりやすくなります
- [trn1.32xlarge と trn1n.32xlarge](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-hardware/trn1-arch.html) では、NeuronLink-v2 が 16 枚のチップを 2D トーラス（格子の端どうしもつないだ形）でつなぎます

## Trainium2 で加わった機能

Trainium2 は、1 枚に [NeuronCore-v3](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-hardware/neuron-core-v3.html) を 8 個載せています。

- Logical NeuronCore（LNC）が加わりました。次の節で説明します
- 構造化スパースに対応しました。行列の掛け算の入力の片方が、連続する N 個のうち M 個だけが 0 でない形（4:8 や 2:4 など）のときに使える機能で、[チップ全体で最大 2,563 TFLOPS](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-hardware/trainium2.html) です
- cFP8 の指数バイアスを調整できるようになりました。cFP8 は、初代 Trainium の NeuronCore-v2 から使える 8 ビットの浮動小数点の形式です。一般に、指数バイアスをずらすと、表せる数の範囲が大きい側や小さい側に動きます
- [Trn2 UltraServer](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-hardware/trn2-arch.html) では、64 枚のチップを 1 つのまとまりにします

## Trainium2 の Logical NeuronCore

![Trainium2 の既定の LNC=2 では、HBM のバンクを共有する 2 個の物理コアが 1 個の論理コアに見える](/images/976e375fd47726-trainium2-lnc.png)

[Logical NeuronCore（LNC）](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-features/logical-neuroncore-config.html)は、物理的なコアを何個ずつまとめて、ソフトウェアに 1 個のコアとして見せるかを決める設定です。**コアをまとめると、学習や推論で動かすワーカープロセスの数を減らせます。**図の右が Trainium2 の既定の LNC=2 で、2 個の物理コアが 1 個の論理コアになり、チップ 1 枚は 4 個のコアに見えます。図の左の LNC=1 では、8 個の物理コアがそれぞれ 1 個のコアに見えます。図の下の札は、ソフトウェアから見えるコアの名前で、LNC=1 では NC_v3、LNC=2 では NC_v3d です。Trainium2 を 16 枚載せた trn2.48xlarge では、LNC=2 で 64 個、LNC=1 で 128 個のコアになります。

Trainium2 の HBM は 24GB のバンク 4 本に分かれていて、1 本を 2 個の物理コアが共有しています（バンクの容量は LNC のページの表記で、チップ全体は Trainium2 のページで 96 GiB です）。LNC=2 では、この 2 個が 1 つのメモリの番地の範囲（アドレス空間）を共有します。LNC は、実行時の設定とコンパイラの設定の 2 か所で指定します。使える値は 1 と 2 だけです。2 か所には同じ値を指定します。

## Trainium3 で加わった機能

Trainium3 は、1 枚に [NeuronCore-v4](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-hardware/neuron-core-v4.html) を 8 個載せています。Trainium3 でも、LNC を 1 か 2 に設定して使えます。

- MXFP8 と MXFP4 に対応しました。どちらも業界団体 OCP（Open Compute Project）の [MX 規格](https://www.opencompute.org/documents/ocp-microscaling-formats-mx-v1-0-spec-final-pdf)に沿った形式で、規格では 32 個の値が 1 つの倍率を共有します。Tensor Engine は、MXFP4 の値を計算の直前に MXFP8 に変換します。公式の性能表は、MXFP8 と MXFP4 の両方を 2,517 TFLOPS と書いています。MXFP4 は値 1 つあたりのビット数が MXFP8 の半分なので、同じ数の値を少ないメモリで置けます
- SRAM の近くで足し算ができるようになりました（near-memory accumulation）。次の節で説明します
- Vector Engine に 2 つの機能が加わりました。1 つは、BF16 や FP16 の値をその場で MXFP8 に変換する機能で、MLP（多層パーセプトロン）の層と層の間で使えます。もう 1 つは指数関数の計算で、Scalar Engine の 4 倍の処理量（スループット）があります。公式は、この機能が Self-Attention の高速化に役立つと書いています
- [NeuronSwitch-v1](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-hardware/trn3-arch.html) で、チップ同士をスイッチでつなぐ形になりました。Trn3 UltraServer では、Gen1 で 64 枚、Gen2 で 144 枚のチップを 1 つのまとまりにします

## Trainium3 の near-memory accumulation

![NeuronCore-v4 では、DMA が 1 回の転送で SRAM の値 A に B を足し込む](/images/976e375fd47726-near-memory-accumulation.png)

SRAM にすでにある値 A に、外から届いた値 B を足し込む場面を考えます。DMA（Direct Memory Access）は、メモリの間でデータを運ぶ専用の回路です。図の上の段は、この機能を使わない場合の一般的な手順です。DMA が B を SRAM の空いた場所にコピーします。次にエンジンが A と B を読んで足し、A に書き戻します。NeuronCore-v4 では、図の下の段のように、[DMA が 1 回の転送で A を読み、B を足し、A に書き戻します](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-hardware/neuron-core-v4.html)。

## まとめ

Trainium のチップ 1 枚は、Trainium2 でコアが 2 個から 8 個に増え、Trainium3 で MXFP8 と MXFP4、スイッチによるチップ同士の接続が加わりました。下の表の値はチップ 1 枚あたりで、[Trainium](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-hardware/trainium.html)、[Trainium2](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-hardware/trainium2.html)、[Trainium3](https://awsdocs-neuron.readthedocs-hosted.com/en/latest/about-neuron/arch/neuron-hardware/trainium3.html) の各ページから 2026-10-04 に取りました。初代の HBM 帯域、SBUF、チップ間の通信、CC-Cores は Trainium2 のページの比較表の値で、最後の行だけはインスタンスや UltraServer の構成の値です。SBUF は公式の比較表の項目名で、Trainium2 と Trainium3 では、コア 1 個の SRAM の容量の 8 倍と同じ値です。

| --- | --- | --- | --- |
| NeuronCore | v2 x 2 | v3 x 8 | v4 x 8 |
| FP8 (TFLOPS) | 190 (cFP8) | 1,299 (cFP8) | 2,517 (MXFP8) |
| MXFP4 (TFLOPS) | - | - | 2,517 |
| BF16 / FP16 / TF32 (TFLOPS) | 190 | 667 | 671 |
| FP32 (TFLOPS) | 47.5 | 181 | 183 |
| スパース (TFLOPS) | - | 2,563 (FP8 / FP16 / BF16 / TF32) | 2,517 (FP16 / BF16 / TF32) |
| HBM 容量 (GiB) | 32 | 96 | 144 |
| HBM 帯域 (TB/s) | 0.8 | 2.9 | 4.9 |
| SBUF (MiB) | 48 | 224 | 256 |
| DMA 帯域 (TB/s) | 1 | 3.5 | 4.9 |
| チップ間の通信 (GB/s) | 384 | 1,280 | 2,560 |
| NeuronLink | v2 | v3 | v4 + NeuronSwitch-v1 |
| CC-Cores | 6 | 16 | 16 |
| 1 つにつながるチップ数 | 16 (trn1.32xlarge) | 64 (Trn2 UltraServer) | 64 / 144 (Trn3 UltraServer Gen1 / Gen2) |
