# はじめに

ML 分散学習・推論の実験を、Amazon EKS 上で回すための基盤を Terraform で構築するワークショップを作りました。この基盤は、AWS が公開する分散学習リファレンス実装 [awslabs/awsome-distributed-ai](https://github.com/awslabs/awsome-distributed-ai/tree/main) を参考にしながら組み立てています。まず NVIDIA GPU で動く構成を土台に据えつつ、AWS Trainium への対応も今後目指しています。

https://zenn.dev/tosshi/books/eks-distributed-ai

作った背景としては、Slurm 大好きマンなので Slurm で検証を頑張っていたのですが強化学習で GRPO を触ったり、分離推論の検証をするときに llm-d をささっと使いたい、、などとなって Slurm だけで生きていくことに限界を感じたため重い腰を上げて EKS 基盤整理を始めました。AWS には Amazon SageMaker Hyperpod という Slurm と EKS どちらも対応して組み込みで監視や便利機能が搭載されているサービスがあるのでそれを使っても良かったのですが、せっかくなので Vanilla EKS を Terraform で自分で全部組んで動かしておこうという程度の意図でワークショップを作りました。

:::message
ワークショップ実施は完全に自己責任で実施してください。にゃーん。
:::

# コンテンツ

![Amazon EKS 分散 AI 基盤の全体アーキテクチャ](/images/books/eks-distributed-ai/arch-overview.png)

- Terraform による Amazon EKS クラスタの構築 (Basic01)
- GPU を使わない CPU での torchrun DDP 分散学習の体験 (Basic02)
- Karpenter によるノードの動的プロビジョニング (Basic03)
- GPU ノードを追加して torchrun DDP 分散学習を体験 (Basic04)
- Capacity Block (予約 GPU/AWS Trainium) の取得と組み込み (Basic05)
- EFA (Elastic Fabric Adapter) によるマルチノード NCCL 通信の検証 (Basic06)
- 軽量 vLLM による GPU 推論の動作確認 (Basic07)
- Prometheus と Grafana による GPU メトリクスの可視化 (Basic08)
- AWS Trainium (AWS Neuron) 対応 (Basic09)
- Amazon FSx for Lustre による共有ストレージ設計 (Basic10)
- クラスターのお片付け (Basic11)
